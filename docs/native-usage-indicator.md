# 기본 앱의 사용량 경고 조사

2026-11-04에 설치된 Windows 패키지 `OpenAI.Codex` **26.1027.6604.0**을 읽기 전용으로 확인했다. 패키지 조회와 `AppxManifest.xml`의 버전을 대조했으며 manifest의 표시 이름은 `ChatGPT`다. 이 문서는 현재 설치본의 정적 구현에 대한 관찰이며, 지원되는 확장 인터페이스나 향후 버전의 보장이 아니다.

## 확인한 기준

**빨간 경고색의 기준은 반올림 전 잔여율이 15% 미만인 경우다.** 정확히 15%는 이 조건에 포함되지 않는다.

- `webview/assets/rail-menu-6e9be66bc5d9.js`의 원호 렌더링은 `i<15?Y.low:void 0`으로 경고 클래스를 선택한다.
- `webview/assets/33168f9476a7.css`의 해당 `low` 클래스는 `--color-usage-meter-warning` 색상을 사용한다. 렌더링 조건과 실제 스타일을 각각 확인했다.
- 주간 툴팁은 `Math.round(i??r)`로 반올림한다. 반올림 전 14.999%도 툴팁에는 15%로 표시되면서 경고색일 수 있다.
- 입력은 사용한 비율로부터 남은 비율을 계산한다. 기본 앱은 `allowed`일 때 표시 최소값을 1로 두기도 한다. 이 보조 프로그램은 공식 조회의 실제 잔여값을 1%로 바꾸지 않으며, 0%는 소진으로 표시한다.
- 기본 앱이 5시간·주간 원호를 함께 표시하면 각 원호에 경고색 기준을 따로 적용한다. 이번 보조 프로그램의 새 경고는 `codex` 버킷의 10080분 주간 창만 대상으로 한다.

| 반올림 전 잔여율 | 기본 앱의 정수 툴팁 | 15% 미만 경고 조건 |
| --- | --- | --- |
| 15.001% | 15% | 해당 없음 |
| 15.000% | 15% | 해당 없음 |
| 14.999% | 15% | 해당 |
| 14.000% | 14% | 해당 |

동일한 비교식은 보조 프로그램의 경계 검사로도 확인한다. 계정의 실제 한도를 소모하거나 서버 값을 바꿔 경계를 시험하지 않는다. 경고는 새로 확인한 정상 데이터에만 적용하며, 갱신 중·실패·3분 이상 지난 값에는 빨간 최신 경고 대신 기존 상태와 마지막 확인 시각을 표시한다.

## 확인하지 못한 기준

**위 15%는 기본 아이콘이 처음 나타나는 임계값을 뜻하지 않는다.** 연결된 selector와 footer 렌더링에는 기능 게이트, 접근 조건, ChatGPT 인증, 계정·사용자 일치 및 `ambient_usage` 제공 여부 등이 존재한다. 확인한 이 연결 경로에서는 `<15`를 아이콘의 표시 여부 조건으로 사용하는 부분을 찾지 못했다. 서버가 `ambient_usage`를 어떤 기준으로 제공하는지는 확인하지 않았다.

따라서 사용자가 14%에서 아이콘을 보았다는 사실만으로 “15% 미만부터 아이콘이 나타난다”고 결론 내리지 않는다. 계정 조건이나 배포 상태의 실제 값도 이번 조사에서 읽거나 변경하지 않았다.

표시 조정을 위한 감지 대상은 정적 코드상 `사용량`/`Usage` 이름의 버튼이며, 주간 잔여량 설명이 연결된다. 그러나 현재 도구의 접근성 읽기에서는 이 버튼의 역할·좌표·화면 밖 여부를 독립적으로 확인하지 못했다. 대화에도 나타날 수 있는 `사용량` 단어만으로 버튼이 보인다고 판단하지 않는다. 이는 Windows UI Automation으로 감지할 수 없다는 결론이 아니라, 실제 노출 속성 확인이 아직 필요하다는 뜻이다. 자동 감지·숨김은 미구현이며, 향후 감지 실패나 시간 초과도 “기본 표시 없음”과 구분해 “확인 불가”로 다뤄야 한다.

검토한 [공식 설정 안내](https://learn.chatgpt.com/docs/app/settings)와 [공식 변경 이력](https://learn.chatgpt.com/docs/changelog)에서는 Windows 아이콘의 정확한 출현 임계값이나 항상 표시 토글에 대한 근거를 찾지 못했다. 공식 App Server의 [한도 조회](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)는 잔여량 계산에 쓰는 한도 데이터를 문서화하지만 기본 UI의 출현 조건을 보장하지 않는다.
