## 0.6.18

0.6.18은 C# 자체 검사 501개를 통과했습니다. Pro 세 가지 표시명과 나머지 요금제 표시 유지, 갱신 실패·갱신 중·만료 때 등급명이 포함된 이전 값 표시를 확인했습니다. 자체 배지 창 GDI 자원 수는 전후 43개였습니다. 이번 변경은 표시명만 바꾸며 Node 조회 코드는 수정하거나 다시 검사하지 않았습니다. 일반 Overlay 실행·실제 계정 조회·새 화면 렌더링은 수행하지 않았습니다.

상태·연결 테스트와 좌표 계산 검사가 포함돼 있습니다. 자체 검사에는 주간 경고의 15% 경계, 소수·0%, 한도 종류 구분, 오래된 값과 실패 상태 검사도 포함됩니다. 과거 트레이 프로토타입에서는 두 표시 위치, 150% 배율, 클릭 통과, ChatGPT 창의 최대화·최소화·복원, 정상·강제 종료를 실제 창에서 확인했습니다.

2026-11-04 사용자가 승인한 **0.4 고정 설치본**의 실제 실행에서 일반 창 최소화 중 표시 유지·정기 조회와 X 종료를 확인했습니다. 약 77초간 실행 진단에서 표시 상태와 갱신 시각을 확인했고, X 후 앱과 소유 조회 프로세스·콘솔 호스트 5개가 모두 종료됐습니다. 실행 전·중·종료 후 트레이 기록은 Overlay 0개였으며 자동 시작 설정도 전후 동일했습니다.

0.5.2의 자체 검사 78개가 통과했습니다. 실행 경로, 실제 제목 기준 좌표 계산, 수동 보정, DPI·창 경계, 기존 설정 전환, 느린 접근성 조회·결과 만료·종료와 주간 경고를 확인했습니다. 현재 Reader/Layout과 동일한 소스를 사용하는 숨김 읽기 전용 프로브로 `OpenAI.Codex 26.1029.7803.0`의 실제 창도 세 차례 읽었습니다. 150% 배율에서 클라이언트 영역 `(59, 104, 2944, 1877)`, 제목 `(585, 195, 199, 28)`, 헤더 `(507, 170, 2491, 78)`을 읽고 배지 영역 `(585, 257, 336, 69)`을 계산했습니다. 각 값은 화면 좌표의 `(왼쪽, 위, 너비, 높이)`이며, 세 조회는 모두 성공했고 171·2·1ms가 걸렸습니다.
