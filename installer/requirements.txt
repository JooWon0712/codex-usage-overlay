Codex Usage Overlay 설치 안내

이 설치 프로그램은 현재 Windows 사용자 계정에만 설치합니다.
기본 위치: %LOCALAPPDATA%\Programs\CodexUsageOverlay
이미 설치한 버전이 있으면 이전에 선택한 폴더를 사용합니다.

Node.js와 Codex CLI가 별도로 설치되어 있어야 합니다.
Codex CLI에 로그인한 계정의 공식 사용량 조회를 사용합니다.
이 설치 프로그램은 Node.js 또는 Codex CLI를 설치하거나 로그인하지 않습니다.
연결된 CLI 계정과 Codex 데스크톱 계정이 같은지 확인하세요.

설치 후 앱을 자동으로 실행하거나 Windows 로그인 자동 시작을 등록하지 않습니다.
시작 메뉴 바로가기로 실행할 수 있으며, 바탕 화면 바로가기는 선택 사항입니다.

업데이트 또는 제거할 때 실행 중인 앱은 사용자의 동의 후 정상 종료를 요청합니다.
앱이나 소유 작업의 종료를 확인하지 못하면 파일을 변경하지 않습니다.
오래된 버전은 먼저 X 또는 종료 버튼으로 직접 닫아야 할 수 있습니다.

사용자 설정(%LOCALAPPDATA%\CodexUsageOverlay)은 업데이트와 제거 시 보존합니다.
설치 폴더의 runtime-paths.json도 덮어쓰거나 제거하지 않습니다.
포터블 사본의 파일은 변경하지 않습니다. 앱은 설치본과 포터블을 합쳐 한 번만 실행됩니다.
